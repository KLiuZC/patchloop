## 问题

`parse_version("1.2.3")` 可以正常返回 `(1, 2, 3)`，但 `parse_version("v1.2.3")` 会抛出 `ValueError`。

## 期望行为

- 支持开头恰好一个小写 `v`：`v1.2.3` 应返回 `(1, 2, 3)`。
- 普通版本号的行为保持不变，包括 `0`、`2.10` 和 `01.002`。
- 大写 `V`、重复 `v`、仅有 `v`、空字符串、空版本段或非数字版本段仍应抛出 `ValueError`。
