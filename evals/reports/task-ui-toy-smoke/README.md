## 目标与版本

用户从网页提交版本号解析任务，再通过 `agent worker --task-id` 运行指定任务。收尾检查覆盖网页结果读取、列表入口、刷新恢复、补丁下载，以及 API、SQLite、修复产物的一致性。

实现版本为运行前已提交的 `07bbc8e3c4144d41eef0a410e9ef1342a45f9880`（`feat/task-ui`）。运行前和收尾归档前均检查工作区干净。玩具任务位于同一仓库，因此待修复基线恰好也是这个提交；实现版本与任务基线仍是两个不同概念。

这是单个已有玩具任务的工程验收，不是 SWE-bench 官方判卷，不纳入开发集或留出集成功率。网页提交由用户完成；本次收尾在运行结束后只读检查，没有重新提交、调用模型或重跑测试。排队到运行的页面转换没有在收尾中现场观察。
